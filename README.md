# marcketplace

Tienda en línea (marketplace) hecha con HTML, CSS y JavaScript puro, sin dependencias.

## Funciones

- Catálogo de productos con búsqueda y filtro por categoría
- Ordenar por precio o valoración
- Carrito de compras guardado en el navegador (`localStorage`)
- Envío gratis en compras mayores a $50

## Ver en local

Abre `index.html` en tu navegador, o ejecuta:

```
python3 -m http.server 8000
```

y visita http://localhost:8000

## Publicación

El sitio se publica con GitHub Pages desde la rama `main` (carpeta raíz).
